1. JavaScript Fundamentals

Asked in every MERN interview — master these first.

Q: Difference between var, let, and const?
  • var — function-scoped, hoisted with undefined, can be redeclared
  • let — block-scoped, hoisted but in "temporal dead zone," can be reassigned
  • const — block-scoped, must be initialized, can't be reassigned (object properties can still be mutated)
Q: What is a closure?

A function that retains access to its outer scope's variables even after the outer function has returned. 

function counter() {
  let count = 0;
  return () => ++count;
}
const increment = counter();
increment(); // 1
increment(); // 2 — count persists via closure
Q: Explain the event loop (output prediction).
console.log('1');
setTimeout(() => console.log('2'), 0);
Promise.resolve().then(() => console.log('3'));
console.log('4');
// Output: 1, 4, 3, 2

Synchronous code runs first → microtasks (promises) → macrotasks (setTimeout, setInterval).

Other must-know topics

  • Hoisting, this keyword, arrow functions vs regular functions
  • call, apply, bind
  • Promises vs async/await; Promise.all vs allSettled vs race
  • Shallow vs deep copy (structuredClone, spread operator limitations)
  • Prototypal inheritance
  • ES6+: destructuring, spread/rest, optional chaining, nullish coalescing

2. Node.js

Q: What is Node.js and how does it handle concurrency?

A JavaScript runtime built on Chrome's V8 engine. It is single-threaded but handles concurrency via an event-driven, non-blocking I/O model — I/O operations are delegated to the libuv thread pool while the main thread keeps processing events.

Q: process.nextTick() vs setImmediate()?
  • process.nextTick() — fires before the event loop continues (before microtasks)
  • setImmediate() — fires in the check phase of the event loop (after I/O)
Q: What are streams?

Objects for handling data piece-by-piece instead of loading everything into memory. Four types: Readable, Writable, Duplex, Transform. 

fs.createReadStream('big.txt').pipe(res); // memory-efficient file serving
Q: How do you scale a Node.js app?
  • Cluster module — fork worker processes per CPU core
  • Worker threads — for CPU-intensive tasks
  • Load balancing — nginx, PM2
  • Horizontal scaling with stateless design

Other must-know topics

  • CommonJS (require) vs ES Modules (import)
  • package.json vs package-lock.json
  • Buffer, EventEmitter
  • Error handling: uncaught exceptions, unhandled rejections
  • Environment variables (dotenv)

3. Express.js

Q: What is middleware?

Functions with access to req, res, and next that execute in order during the request-response cycle. Used for logging, auth, parsing, error handling. 

app.use(express.json());                  // built-in
app.use('/api', authMiddleware);          // custom, path-specific
app.use((err, req, res, next) => {        // error handler (4 args!)
  res.status(err.status || 500).json({ message: err.message });
});
Q: Route params vs query params?
  • req.params → /users/:id → /users/42
  • req.query → /users?sort=name&page=2
Q: JWT vs Sessions?
JWT Sessions
Storage Client (stateless) Server (stateful)
Scalability Excellent Needs shared store (Redis)
Revocation Hard (until expiry) Easy (delete session)
Best for APIs, microservices Traditional web apps
Q: Write a JWT auth middleware.
const auth = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) return res.status(401).json({ message: 'No token' });
  try {
    req.user = jwt.verify(token, process.env.JWT_SECRET);
    next();
  } catch {
    res.status(401).json({ message: 'Invalid token' });
  }
};

Other must-know topics

  • CORS — what it is and how to configure it
  • Security: helmet, rate limiting, input sanitization, NoSQL injection prevention
  • REST design: proper verbs; status codes 200, 201, 204, 400, 401, 403, 404, 500
  • File uploads with multer

4. MongoDB

Q: SQL vs NoSQL — when to use MongoDB?

MongoDB stores flexible, JSON-like documents (BSON) in collections. Choose it for flexible schemas, rapid iteration, horizontal scaling, hierarchical data. Choose SQL for complex joins, strict schemas, multi-row transactions.

Q: Embedding vs Referencing?
  • Embed — data accessed together, "contains" relationship (user + address)
  • Reference — data is large, shared, or updated independently (posts + authors) 
// Referencing with Mongoose populate
const postSchema = new mongoose.Schema({
  title: String,
  author: { type: mongoose.Schema.Types.ObjectId, ref: 'User' }
});
Post.find().populate('author', 'name email');
Q: Explain the aggregation pipeline.
db.orders.aggregate([
  { $match: { status: 'delivered' } },            // filter
  { $group: { _id: '$customerId',
              total: { $sum: '$amount' } } },     // group
  { $sort: { total: -1 } },                       // sort
  { $limit: 5 }                                   // top 5 customers
]);

Know: $match, $group, $project, $lookup (joins), $unwind, $sort, $limit.

Q: What are indexes?

B-tree data structures that speed up queries at the cost of write performance and storage. Types: single field, compound, text, unique. Verify usage with .explain().

Other must-know topics

  • Replication (high availability) vs Sharding (horizontal scaling)
  • Mongoose: schemas, models, pre/post hooks, virtuals, validation
  • Multi-document ACID transactions
  • findOneAndUpdate options (new: true, upsert)
  • ObjectId structure (timestamp + random + counter)

5. React

Q: What is the Virtual DOM?

An in-memory representation of the real DOM. On state changes, React creates a new virtual tree, diffs it against the previous one (reconciliation), and applies only minimal changes to the real DOM.

Q: Explain the key hooks.
// useState — state in functional components
const [count, setCount] = useState(0);
setCount(prev => prev + 1); // functional update avoids stale state

// useEffect — side effects + cleanup
useEffect(() => {
  const id = setInterval(tick, 1000);
  return () => clearInterval(id);  // cleanup on unmount
}, []); // empty deps = run once on mount

// useRef — mutable value, no re-render on change
const inputRef = useRef(null);
Q: useMemo vs useCallback?
  • useMemo(() => compute(a, b), [a, b]) — memoizes a computed value
  • useCallback(fn, deps) — memoizes the function itself (pairs with React.memo to prevent child re-renders)
Q: Controlled vs uncontrolled components?
  • Controlled — form value driven by React state (value + onChange)
  • Uncontrolled — DOM holds the value, accessed via refs
Q: Why are keys important in lists?

Keys help React identify which items changed, were added, or removed during reconciliation. Using array index as key causes bugs when lists reorder.

Q: Write a custom hook (useFetch).
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const controller = new AbortController();
    setLoading(true);
    fetch(url, { signal: controller.signal })
      .then(res => res.json())
      .then(setData)
      .catch(err => err.name !== 'AbortError' && setError(err))
      .finally(() => setLoading(false));
    return () => controller.abort();
  }, [url]);

  return { data, loading, error };
}

Other must-know topics

  • Rules of hooks (top level only, only in React functions)
  • Context API vs Redux — when to use each; Redux Toolkit basics
  • Prop drilling and solutions
  • React.memo, lazy loading, Suspense, code splitting
  • Error boundaries
  • React Router: useNavigate, useParams, protected routes
  • React 18: concurrent rendering, automatic batching, useTransition

6. Full-Stack Integration

Q: Walk through the flow of a MERN request.

User submits form → React handler calls API (fetch/axios) → Express route receives request → middleware validates/authenticates → controller queries MongoDB via Mongoose → response sent as JSON → React updates state → UI re-renders.

Q: End-to-end authentication flow?
  1. User logs in → server validates → signs JWT → returns token
  2. Client stores token (httpOnly cookie preferred over localStorage for XSS safety)
  3. Client sends token in Authorization: Bearer <token> header
  4. Server middleware verifies token on protected routes
  5. Refresh token rotation for long sessions
Q: How do you handle CORS?
app.use(cors({ origin: 'https://yourfrontend.com', credentials: true }));

Other topics

  • Environment configuration (dev vs prod)
  • Deployment: frontend (Vercel/Netlify), backend (Render/Railway/AWS), MongoDB Atlas
  • WebSockets with Socket.io for real-time features
  • Pagination: offset vs cursor-based

7. Common Coding Challenges

Q: Implement debounce (asked constantly).
function debounce(fn, delay) {
  let timer;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}

Typical live-coding tasks

  • Todo app with add/delete/toggle (React)
  • Fetch and display API data with loading/error states
  • CRUD REST API (Express + MongoDB)
  • Flatten a nested array / deep clone an object
  • Search filter with debounced input
  • Counter with useReducer
